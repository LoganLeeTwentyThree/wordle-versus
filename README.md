# WordleVS
WordleVS is an example website hosted at https://wordlevs.loganlee.xyz/ that showcases the functionality of the [gameroom typescript package](https://github.com/LoganLeeTwentyThree/gameroom) for Durable Objects. 

Check out `worker/index.ts` for real code using gameroom.
Check out `src/` for the front end code that talks to the gameroom.
